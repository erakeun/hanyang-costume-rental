하냥이 인형탈 대여 시스템 v1.0
================================

구성
----
1. Code.gs
2. Index.html

이 버전은 GitHub Pages가 아니라 Google Apps Script Web App 자체에서 화면과 서버를 함께 운영합니다.
이유: google.script.run을 사용하면 별도 CORS/API 연결 없이 신청, 달력, DB, 승인/거절 처리를 한 프로젝트에서 안정적으로 운영할 수 있습니다.

설치 순서
---------
1. https://script.google.com 에서 새 프로젝트 생성
2. 기본 Code.gs 내용을 전부 삭제하고 이 폴더의 Code.gs를 붙여넣기
3. 좌측 + 버튼 > HTML > 파일 이름을 "Index"로 생성
4. Index.html 내용을 전부 붙여넣기
5. 저장
6. 함수 선택에서 setupSystem 선택 후 "실행"
7. 권한 승인
8. 실행 로그에 생성된 "관리 스프레드시트" URL 확인
9. 우측 상단 "배포" > "새 배포" > 유형 "웹 앱"
10. 실행 사용자: 나
11. 액세스 권한: 실제 신청 대상에 맞게 설정
    - 외부에서도 신청 가능해야 하면 허용 범위를 넓혀야 함
    - 학교 Google Workspace 정책에 따라 선택지가 다를 수 있음
12. 배포 후 /exec 로 끝나는 웹 앱 URL 사용

현재 자동 차단
--------------
- 개인 신청
- 상업적 사용
- 야간 사용
- 우천 환경 사용
- 동행자 없음
- 기존 "접수" 또는 "승인" 일정과 날짜 중복

경고 후 신청 가능
-----------------
- 착용자 신장이 160~169cm 범위를 벗어남
- 교외/외부 장소 사용

승인 처리 방식
--------------
관리 메일에는 "승인 검토", "거절 검토" 버튼이 들어갑니다.
버튼은 GET 방식으로 검토 페이지를 여는 역할만 하며 상태를 바꾸지 않습니다.
실제 승인/거절은 검토 페이지의 최종 버튼을 POST로 눌러야 처리됩니다.
따라서 메일 보안 솔루션의 자동 링크 검사 때문에 실수로 승인되는 구조를 피했습니다.

DB
--
setupSystem()이 Google Sheets를 자동 생성합니다.
신청 DB에서 상태는 접수 / 승인 / 거절로 관리됩니다.

운영 전 확인할 정책
-------------------
현재 "야간"의 정확한 시간 기준은 코드에 숫자로 넣지 않았습니다.
사이트에서 "야간 사용 여부"를 직접 묻고 "예"면 차단하는 구조입니다.
추후 18시 이후 등 정확한 기준을 정하면 시간 입력 방식으로 바꿀 수 있습니다.
